# Platform Decisions

**Production-grade cloud architecture on Azure and AWS — the decisions, the trade-offs, and what breaks.**

This is the companion code for the [Platform Decisions YouTube channel](https://youtube.com/@PlatformDecisions).
Every video ships with working code and diagrams so you can see the design, run it, and adapt it.

## What you'll find here

- **Terraform** for Azure and AWS patterns shown on the channel: private networking, landing zones, identity, CI/CD
- **Architecture diagrams** (source files you can edit)
- **Scripts and checklists** for troubleshooting and day-to-day platform work
